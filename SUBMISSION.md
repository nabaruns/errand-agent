## Checking it in five minutes

```bash
git clone https://github.com/nabaruns/errand-agent && cd errand-agent
uv sync
uv run pytest                     # 94 tests, no API key needed
uv run python -m evals.run        # regenerates the eval table
```

To talk to the live agent, put `CLAUDE_API_KEY=...` in `.env` and run `uv run errand-web --seed-demo`, then
open http://127.0.0.1:8765.
